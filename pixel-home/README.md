# Pixel Home

Pixel Home için bağımsız, responsive portfolyo sitesi. GitHub Pages üzerinde `/pixel-home/` alt yolunda çalışır.

## Yapı

- `index.html`: ana sayfa
- `projects/*/index.html`: beş proje detay sayfası
- `project.js`: proje içerikleri ve sayfa verileri
- `styles.css`: ortak responsive tasarım sistemi
- `assets/images`: optimize WebP görseller
- `assets/videos`: web için sıkıştırılmış MP4 videolar

## Yerel kontrol

```bash
python3 -m http.server 4173
```

Ardından `http://localhost:4173/pixel-home/` adresini açın.

Tüm portfolyo çalışmaları bağımsız konsept çalışmadır ve marka iş birliği değildir.
