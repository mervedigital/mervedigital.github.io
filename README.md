# Merve Övür — Kişisel Web Sitesi

Responsive, statik ve production-ready kişisel marka sitesi.

## Canlı site

https://mervedigital.github.io/

## Yerelde çalıştırma

```bash
python3 -m http.server 4173 --directory .
```

Ardından `http://localhost:4173` adresini açın.

## İçerik doğrulama notları

- Akademinin resmî adı yüklenen logoda görüldüğü biçimiyle `UGC & AI Collaby Academy` olarak kullanıldı.
- Katılım bedeli `369 USD` olarak gösterildi; ödeme türü ve erişim koşulları kayıt ekranına bırakıldı.
- Kişisel destek, düzenli birebir görüşme sözü verilmeden `kişisel mentörlük ve özel grup desteği` olarak ifade edildi.
- Yorum, kazanç, müşteri sayısı veya garanti niteliğinde gerçek dışı sonuç kullanılmadı.

## Dosyalar

- `index.html`: Semantik sayfa yapısı ve Türkçe içerikler
- `styles.css`: Responsive tasarım sistemi ve erişilebilir hareket tercihleri
- `script.js`: Mobil menü, açılır sorular ve görünüm animasyonları
- `assets/`: Optimize edilmiş WebP görseller
